# 德阳慢慢玩

2026 年 11 月 16—17 日两人旅行图文路书。GitHub Pages 部署的是独立静态攻略，不是 TREK 服务端。网页包含每日安排、地点卡片、照片来源、高德位置、两种返程方案、可在当前浏览器保存的预算和清单，并附可导入 TREK 的 GPX 地点文件及日历文件。

- 在线图文攻略：仓库启用 GitHub Pages 后访问仓库对应的 Pages 地址。
- `assets/deyang-trek-places.gpx`：地点标记；可导入 TREK 的 Places，不包含预订、完整时间表或账本。
- `assets/deyang-calendar.ics`：供日历应用导入的建议行程，不代表已预订。
- 图片使用外部原始地址并在页面标注来源；外部图片或地图可能受网络影响。
- 预算、收藏和待办保存在访问者的浏览器本地，不跨设备自动同步。
- 运行 `node generate-assets.mjs` 可从 `trip-data.js` 重建 GPX 与日历文件。

资料采集于 2026-11-15；交通、营业、房价及天气需以当天官方渠道为准。
