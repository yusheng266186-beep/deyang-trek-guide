# 慢慢同行 · 德阳两人旅行手记

为 2026 年 11 月 16—17 日设计的手机图文路书，公开页面：[打开攻略](https://yusheng266186-beep.github.io/deyang-trek-guide/)。页面是独立静态网站，不是原版 TREK 的在线服务端。

- 行程：经典市区、旌湖慢走、三星堆专程三套时间表，取行李和德阳站返程按车次倒推。三星堆需提前预约，并单独预留跨城交通与费用。
- 地图：高德原生嵌入地图提供老城、市区和广汉三种范围，支持全屏、缩放、分类筛选、选定地点和路线；推荐地点用彩色编号区分类别，可比较两地直线距离。免密钥嵌入地图一次标注一个指定地点，无法同时显示全部自定义彩色标记；高德分类搜索可能包含清单以外地点。区域参考点有明确标注。行程顺序示意会随路线切换。两地选择使用支持键盘的自定义选择面板，手机上从底部弹出。
- 吃玩：景点参考图及来源、美食分类、住宿候选、车站实景和两种返程方案。酒店与车票均未预订，营业、房价、余票和天气须出行前重新确认。
- 预算、收藏、清单和减少动效设置保存在当前浏览器；分享链接携带所选路线与车次，不会实时同步其他内容。
- `assets/deyang-trek-places.gpx`：地点标记，可导入 TREK 的 Places；不包含预订、完整时间表或账本。
- `assets/deyang-calendar*.ics`：按三条路线生成的建议日历，选择一份导入；不包含已预订车次提醒。
- 图片引用各平台原始地址并标注来源，地图及图片需要网络，可能因第三方服务或网络状况不可用。
- 运行 `node generate-assets.mjs`，可从 `trip-data.js`、`content-v2.js` 重建 GPX 和三份日历。

车次核对时间见页面；资料采集于 2026 年 11 月 15 日。地图、交通时间、价格、营业及开放情况均应以当日官方渠道为准。
