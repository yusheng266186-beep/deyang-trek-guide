01 / THE ITINERARY

这两天，这样过。

留足拍照、吃饭和休息的时间，城市不大，慢一点刚刚好。

旅行方式一晚住宿 · 一天漫游
步行 + 市内打车

时间是建议，可按你们的节奏调整。

DAY 01 / MONDAY

先把行李放下，
去老城吃一顿。

16
NOV
18:00文庙商圈 · 办理入住约 30 分钟 / 双床目标约 ¥300+

优先选文庙广场、庙街一带，附近吃饭方便，第二天去文庙和回来取行李也顺路。入住时间可按你们实际安排移动。

到店确认：双床、有窗、第二天退房时间、行李寄存和晚到保留房间。房价及房态需要在平台实时核对。

比较酒店候选 →
18:30晚饭：在地干锅或老城小吃约 1—1.5 小时 / 按营业情况二选一+

想吃一顿热乎的：可先查勇记干锅居（龙山街 9 号，新洋洋百货 2 层），两人先问小份与辣度。想边逛边吃：去文庙广场、城隍庙街，挑凉粉、春卷或豆花。

老店晚间可能提前收摊；不要为单一店铺空腹等太久。点单前可说少辣、不加花生或香菜。

看美食卡片 →
20:00文庙广场附近 · 随意走走约 30—60 分钟 / 随时可回酒店+

逛广场和周边步行街，买水和第二天早餐需要的东西。周一文庙通常闭馆，内部留给周二，不必为了夜景赶时间。

DAY 02 / TUESDAY

一座文庙，一段石刻，
再去湖边吹吹风。

17
NOV
08:00早餐、退房与行李寄存约 50 分钟 / 酒店 → 文庙+

吃完早餐后退房、寄存行李并确认取件地点。住在推荐商圈的话可步行去文庙；具体时间看酒店位置。

想吃德阳特色早餐，可先看城隍庙街的油茶是否营业，时间紧就直接在酒店附近吃。

09:00德阳文庙 · 看红墙和古建筑09:00—10:30 / 免费+

从万仞宫墙、棂星门和泮池看起，继续到礼乐亭、大成殿。两个人可以交替拍照，也可以听馆方语音导览了解建筑故事。

常规 09:00—17:30，17:00 停止入场；若遇临时调整以馆方公告为准。

查看地点详情 →
10:30城隍庙街 · 两人分着吃10:30—11:00 / 文庙附近步行+

王凉粉、伤心春卷选一两样尝鲜即可；天气凉想吃热的，可以询问热凉粉或豆花。小摊有可能搬迁或售罄，现场看情况。

查看王凉粉 →
11:00步行或打车去石刻公园步行约 20—30 分钟 / 或打车 5—10 分钟+

在高德选择「德阳石刻公园」的合适入口，导航会随你们当时的位置调整。步行是时间估算；下雨、提重物或不想走就直接打车。

打开石刻公园位置 ↗
11:25石刻公园 · 看雕塑、拍长廊11:25—12:10 / 通常免费+

重点看石刻艺术墙、长廊与石柱；按出口和体力选择一段即可。喜欢拍照可以多待 20 分钟，后面的咖啡休息略缩短。

查看地点详情 →
12:10午饭 · 片粉、豆花或面12:10—13:00 / 在石刻公园附近选店+

查肖记片粉当日营业状态与实际位置；如果已吃过凉粉，就选豆花、牛肉面或川菜，避免两顿都吃凉食。

查看肖记片粉 →
13:00打车去东湖山公园预计 15—25 分钟 / 约 ¥15—30 每车+

目的地输入「东湖山公园」，上车前核对入口。车费和耗时只是估算，以叫车页面为准。

打开东湖山位置 ↗
13:25东湖山 · 在湖边慢慢走13:25—15:00 / 免费+

沿湖和林荫道散步，找椅子坐一会儿。可以留意水杉林，但 11 月中旬不保证红叶。想看钟鼓楼的话，先选方便的出口。

查看地点详情 →
15:00钟鼓楼外景 / 回酒店取行李15:00—16:00 / 可跳过钟鼓楼+

体力足够时去钟鼓楼广场拍外景，公园不同出口到广场的距离不同；如果天色或体力不合适，直接叫车回酒店。

取行李时再次检查充电线、身份证件、水杯和随身物品。

16:00晚饭、休息，然后一起出发按所选车次倒推离开时间+

附近吃一顿喜欢的晚饭，或找咖啡馆坐一会儿。两人分别购买自贡、泸州的同车次车票，可一起到德阳站进站。
